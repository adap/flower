### What's new?

- **Track token usage in compacted AgentApp contexts** ([#8391](https://github.com/flwrlabs/flower/pull/8391), [#8399](https://github.com/flwrlabs/flower/pull/8399))

  Compacted contexts now store and return their token count through `AgentSession.events`, with unsigned 64-bit fields for series IDs, event boundaries, and token counts.

- **Launch warm-pool tasks without replenishment delays** ([#8280](https://github.com/flwrlabs/flower/pull/8280))

  Ready warm Pods are now handed off before Kubernetes replenishes the pool. Reconciliation creates replacements while tasks run, avoiding Kubernetes list and Pod-creation requests during successful warm token handoff.

- **Train the vertical FL example reliably** ([#8396](https://github.com/flwrlabs/flower/pull/8396))

  The vertical FL example now aligns shuffled features and labels, reuses the model state that produced each embedding, requires complete feature and gradient exchanges, and reports training loss and accuracy from the same model state.

- **Update Python CA bundles and build tools** ([#8400](https://github.com/flwrlabs/flower/pull/8400))

  Flower now requires `certifi>=2026.10.19` and `uv>=0.13.5,<0.14.0`, and its CI, container, and baseline bootstraps use pinned current build tools. Existing installations and images must be updated or rebuilt to receive the new CA bundle.

- **General improvements** ([#8369](https://github.com/flwrlabs/flower/pull/8369), [#8392](https://github.com/flwrlabs/flower/pull/8392), [#8393](https://github.com/flwrlabs/flower/pull/8393), [#8398](https://github.com/flwrlabs/flower/pull/8398), [#8403](https://github.com/flwrlabs/flower/pull/8403), [#8405](https://github.com/flwrlabs/flower/pull/8405))

  As always, many parts of the Flower framework and quality infrastructure were improved and updated.
