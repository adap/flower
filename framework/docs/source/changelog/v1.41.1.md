## v1.41.1 (2026-10-22)

### Security fixes

- Require `certifi>=2026.10.19` and `uv>=0.13.5,<0.14.0` to remove trust in the affected eMudhra/emSign certificate hierarchy.
- Update the CI and container pip bootstraps to pip 26.2.2, which includes the corrected certificate bundle.

See the [Python security announcement](https://discuss.python.org/t/information-for-python-users-regarding-emudhra-emsign-ca-certificate-security-incident/109576) and [Flower #8400](https://github.com/flwrlabs/flower/pull/8400).

Upgrade Flower and recreate containers with the 1.41.1 images after publication. Existing installations and running containers do not receive these changes automatically.
