### What's new?

- **Connect SuperNodes to the Fleet API over HTTP** ([#8301](https://github.com/flwrlabs/flower/pull/8301), [#8303](https://github.com/flwrlabs/flower/pull/8303), [#8304](https://github.com/flwrlabs/flower/pull/8304), [#8305](https://github.com/flwrlabs/flower/pull/8305), [#8307](https://github.com/flwrlabs/flower/pull/8307), [#8308](https://github.com/flwrlabs/flower/pull/8308), [#8309](https://github.com/flwrlabs/flower/pull/8309), [#8310](https://github.com/flwrlabs/flower/pull/8310), [#8311](https://github.com/flwrlabs/flower/pull/8311), [#8313](https://github.com/flwrlabs/flower/pull/8313), [#8314](https://github.com/flwrlabs/flower/pull/8314), [#8315](https://github.com/flwrlabs/flower/pull/8315), [#8316](https://github.com/flwrlabs/flower/pull/8316), [#8317](https://github.com/flwrlabs/flower/pull/8317), [#8318](https://github.com/flwrlabs/flower/pull/8318), [#8320](https://github.com/flwrlabs/flower/pull/8320), [#8321](https://github.com/flwrlabs/flower/pull/8321), [#8322](https://github.com/flwrlabs/flower/pull/8322), [#8325](https://github.com/flwrlabs/flower/pull/8325), [#8333](https://github.com/flwrlabs/flower/pull/8333))

  SuperNodes now connect to the Fleet API over HTTP on the SuperLink's shared `--host` and `--port`, using port `8000` by default. The HTTP API supports SuperNode authentication, version checks, and event logging. SuperLink no longer enables the gRPC Fleet API by default, its `--fleet-api-type` and `--fleet-api-address` options are deprecated, and SuperNode no longer accepts the `--grpc-rere` and `--grpc-adapter` transport options.

- **Search Slack and query Notion meeting notes** ([#8264](https://github.com/flwrlabs/flower/pull/8264), [#8290](https://github.com/flwrlabs/flower/pull/8290), [#8306](https://github.com/flwrlabs/flower/pull/8306), [#8323](https://github.com/flwrlabs/flower/pull/8323))

  The Slack connector now exposes actions for searching public channels or public and private conversations, and stores the authenticated user ID and scopes in its connection configuration. The Notion connector can query AI meeting notes using filters aligned with the Notion MCP schema, and its existing actions provide clearer guidance on identifiers, pagination, and content retrieval.

- **Paginate Control API runs** ([#8276](https://github.com/flwrlabs/flower/pull/8276))

  Control HTTP `ListRuns` requests now return the 20 newest runs when `limit` is omitted and accept `skip` for deterministic offset pagination. The Flower CLI retrieves successive pages when no `--limit` is given, preserving its complete run listing.

- **Continue conversations in the Flower Hub AgentApp** ([#8274](https://github.com/flwrlabs/flower/pull/8274))

  The Flower Hub AgentApp now reconstructs model input from persisted user messages and completed assistant responses, allowing follow-up prompts to retain context across runs in the same conversation.

- **Set federation icons through the Control API** ([#8273](https://github.com/flwrlabs/flower/pull/8273))

  Federations can now store an optional icon key, update or clear it through the Control API, and return it from federation list and detail requests.

- **Configure SQLAlchemy engines during initialization** ([#8281](https://github.com/flwrlabs/flower/pull/8281))

  `SqlMixin.initialize()` now accepts SQLAlchemy engine keyword arguments such as `pool_pre_ping`, `connect_args`, and `poolclass`. Caller-provided SQLite connection and pool settings take precedence while existing defaults remain unchanged.

- **Set up Endeavor with a Flower API key** ([#8324](https://github.com/flwrlabs/flower/pull/8324))

  The Endeavor documentation now includes a dedicated Flower API key setup guide for the macOS CLI and desktop app, with clearer navigation across the Codex and OpenCode guides.

- **Use `AcquireTask` for task polling and claiming** ([#8332](https://github.com/flwrlabs/flower/pull/8332))

  The unused `PullPendingTasks` and `ClaimTask` RPCs, HTTP routes, client methods, and protobuf messages have been removed. Existing clients of these endpoints must switch to `AcquireTask`; requests to the removed routes now return HTTP 404.

- **General improvements** ([#8269](https://github.com/flwrlabs/flower/pull/8269), [#8277](https://github.com/flwrlabs/flower/pull/8277), [#8286](https://github.com/flwrlabs/flower/pull/8286), [#8289](https://github.com/flwrlabs/flower/pull/8289), [#8312](https://github.com/flwrlabs/flower/pull/8312), [#8326](https://github.com/flwrlabs/flower/pull/8326), [#8334](https://github.com/flwrlabs/flower/pull/8334))

  As always, many parts of the Flower framework and quality infrastructure were improved and updated.
